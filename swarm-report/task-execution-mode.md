# Выбор режима выполнения задачи

Пользователь выбирает режим каждой новой задачи. Изменение затрагивает правила харнесса, адаптеры и связанные инструкции навыков. Риск ordinary. Конфигурация обновлена локально.

## Реализация

- Явное указание пользователя задаёт режим сразу. Иначе агент задаёт один вопрос и ждёт ответа. Режим наследуется этапами, навыками, подзадачами и продолжениями.
- В одиночном режиме главная сессия выполняет работу сама. В режиме с субагентами реализация и независимые проверки идут через специалистов. Если выбранный режим недоступен, решение о смене остаётся за пользователем.

## Проверки

- `git diff --check`, YAML-метаданные трёх изменённых навыков, синтаксис расширения Pi через `node --experimental-strip-types --check`, сравнение исходников с установленными копиями через `diff -qr` и проверка ссылок Codex, Claude и Pi прошли. Среда macOS 27.0.1, Node 24.3.0.
- Штатный установщик обновил три управляемых навыка. Хеш SHA-256 проверенного diff до добавления отчёта `8056f7afa83a9b9d9a0b450f685f4d112805287557d36ec8f6534593275e9c82`.
- Согласованность режимов проверена саморевью. Интерактивные прогоны в новых сессиях не запускались.
