# Default: новый PR

Precondition absent PR. Existing → URL + --refresh/--promote hint, stop.
Если draft/ready intent не вытекает из запроса/сессии, выяснить один раз. Ready требует applicable risk-route evidence; draft допускает pending checks.
Заголовок по task/основному commit/branch, ≤70 chars, без WIP/Draft prefix. Body actual final scope, motivation, artifact links, how-to-test и verification (без invented PASS).
Existing applicable labels only, adding not replacing. Reviewers только если назначение явно разрешено пользователем/сессией; можно предложить до 3 authors affected files, excluding current user, но create PR сам по себе не разрешает уведомление третьих лиц. Создать gh/glab PR соответствующего status; body file/stdin. Выход URL/status/существенные limitations.
