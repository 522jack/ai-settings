# Мультиэкспертная проверка

Панель доступна только в режиме с субагентами. В одиночном режиме проверьте документ сами по применимым критериям профиля. Если явно требуется независимая панель, зафиксируйте блокер и согласуйте режим с пользователем. Саморевью не получает вердикт панели.

Вход: artifact file/inline/активный plan, optional profile/slug/roster. Прочитайте сам артефакт, затем [profiles/README.md](profiles/README.md) для detection precedence/negative fields/inventory и **только выбранный** профиль. Unknown explicit profile не fallback. Profile locked на первом cycle; semantic criteria/roster/verdict alphabet/source routing/receipt определяет он.

В режиме с субагентами читайте [mechanism.md](references/mechanism.md). Он задаёт независимость, сбор результатов и повторное ревью.

Для панели выберите доступных reviewers из profile roster с фактическими триггерами. Если обязательная перспектива недоступна, сообщите об этом.

Для панели запускайте независимых reviewers параллельно. Для саморевью используйте критерии профиля без агрегации по голосам. Блокирующие нарушения требуют исправления, повторно проверяйте только затронутые части.

Сообщите согласованный вывод, существенные разногласия и ограничения. Сохраните state и профильный результат, когда их читает другой этап или они нужны для возобновления. PASS не разрешает реализацию или публикацию.
