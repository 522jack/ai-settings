# Маршрутизация к специалистам

Для разового запуска достаточно результата в чате или запрошенного документа. Если результат нужен другому этапу или для возобновления, обновите раздел по `$HOME/dotfiles/ai/shared/rules/task-report.md`.

Навык применяется только после выбора режима с субагентами по `$HOME/dotfiles/ai/shared/AGENTS.md`. Продуктовые изменения и длительные проверки выполняет специалист. Точечное чтение и файлы процесса остаются у main.

1. Выберите минимальный набор реально доступных профилей, которые добавляют нужные критерии или независимость.
2. Передайте задачу, границы, применимые правила и проверки по `$HOME/dotfiles/ai/shared/rules/orchestration.md`.
3. Объедините результаты и открытые риски. Сохраняйте раздел Delegation только при передаче или возобновлении.

Требования к ревью и проверкам определяет `$HOME/dotfiles/ai/shared/rules/workflow.md`.
