# Поиск по коду

Известный файл читать напрямую. Для поиска по имени, тексту или конфигурации использовать точечный поиск. Для usages, иерархий, графов вызовов и других семантических вопросов предпочитать готовый `ast-index` или LSP.

При отсутствии или устаревании индекса сначала проверить, достаточно ли LSP или узкого текстового поиска. Перестраивать индекс, когда семантический результат нужен задаче и нет достаточного доступного способа его получить. Большой файл читать по целевым диапазонам. Если структуру трудно найти, использовать outline.

При смене worktree, отсутствии/устаревании индекса или работе над hooks прочитать [обслуживание индекса](references/ast-index-operations.md). Не предполагать, что watcher уже работает в текущем адаптере.
