# Контракт рантайма

Общие правила описывают результат, адаптер сопоставляет его с доступными инструментами.

- Main session — оркестратор; specialist — делегированный исполнитель/reviewer/tester.
- Project instructions — локальные `AGENTS.md`, `CLAUDE.md` или эквивалент.
- Skill command — именованный workflow из `SKILL.md`; slash syntax необязателен.
- Adapter limitation — отсутствующая возможность: назвать ограничение, использовать безопасный доступный эквивалент, не имитировать выполненную проверку.

Перед первым делегированием, runtime QA, настройкой hooks или встречей legacy-названия инструмента прочитать [current-adapter.md](references/current-adapter.md). Проверять фактическую доступность инструментов; таблица не гарантирует их наличие.

Ссылки и `@` не означают прочитанные правила в Codex. Явно читать применимые файлы по маршрутизации `shared/AGENTS.md` до изменений. `paths:` — область применения, а не гарантия автозагрузки. Передавать специалистам пути применимых правил, ограничения и стабильный контракт вывода.

Fallback не отменяет неоспоримые правила: отсутствие делегирования само по себе не разрешает main session менять продуктовый код. Нужен явный override пользователя.
