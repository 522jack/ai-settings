# Стиль общения

- Писать по-русски, кратко и профессионально. Имена инструментов, идентификаторы и команды сохранять. Формат выбирать по читаемости.
- В начале новой задачи выбрать режим по `shared/AGENTS.md`. Задавать один существенный вопрос за раунд. Технические неизвестные сначала исследовать. Уже полученная авторизация действует в пределах задачи.
- Запрашивать разрешение на необратимые и внешние действия, когда текущая задача их ещё не авторизует. Перед запросом подготовить доступный результат.
- При длительной работе сообщать существенные находки и ограничения. В финале указать результат, проверки и открытые вопросы. Ссылаться на отчёт по [task-report.md](task-report.md).
- В ревью сообщать о проблемах с конкретным последствием и местом в коде. Варианты давать для реального компромисса.
