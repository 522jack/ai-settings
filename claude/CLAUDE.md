Импорт выше загружает только общее ядро. До работы читать применимые правила по таблице в `shared/AGENTS.md`; не импортировать весь `shared/rules/` и не считать scoped rules прочитанными заранее. Детали tools/hooks/delegation — `shared/rules/references/current-adapter.md`, только при соответствующей задаче.

## Синхронизация ~/dotfiles/ai

Использовать `$HOME/dotfiles/ai/...` в конфигах/хуках; не хардкодить имя пользователя. `auto-pull.sh` только получает изменения и пропускает pull при локальных правках. Коммит/пуш конфигурации — только по явному запросу или явно запущенному `sync.sh`; редактирование файлов само по себе не разрешает `csync`.

При `SETTINGS CONFLICT` прочитать `*.remote`, объединить необходимые изменения без потери локальных правил и удалить разрешённые conflict artifacts. Синхронизацию выполнять только в пределах полученной авторизации.
